Fifteen machines are still out there, silent. They are not lost: we know exactly where they are.
Send them a signal and hear what they came to discover.

## What it is

LAST SIGNAL (ÚLTIMA SEÑAL in Spanish) is a scroll-driven 3D museum about NASA hardware that stayed behind after its
mission: landers, rovers, instruments, a helicopter, a telescope and two probes leaving the Solar System. Each machine
tells its own story, from wake-up to last signal, guided by LUMI, a fictional signal companion. Fiction is always
labeled; every fact links to its source.

## Features

- 15 interactive chapters across four acts: the Moon, Mars, small bodies and deep space
- "Send a signal": real light-time estimates from Earth to each machine (JPL orbital elements)
- 15 hands-on mini-experiences (dig a trench, drive a rover with delay, hunt an exoplanet transit…)
- Lunar and Martian atlases, timeline, catalog, passport with original patches, quiz
- Spanish and English, WCAG 2.2 AA, reduced motion, lite mode and a WebGL-free reading mode
- Classroom mode (`?aula=1`) and a 30-second automatic demo (`?demo=1`)
- Optional original music generated live in the browser, an audio mixer (master, music, ambience, effects, voice)
  and narration with the most natural voice the browser offers

## NASA data used

See "NASA Data" in the submission and [`SOURCES.md`](SOURCES.md) (every source, with access date). Mission facts come
from NSSDCA, NASA Science and JPL mission pages; live light times use JPL's approximate Keplerian elements and the JPL
Small-Body Database (433 Eros); photographs come from the NASA Image and Video Library with credit.

## How it works

React + TypeScript + Vite, three.js through React Three Fiber, GSAP ScrollTrigger and Lenis for scroll,
Zustand for state, i18next for languages. One persistent WebGL canvas sits behind the DOM; all content lives
in the DOM so it stays accessible. Every planet, spacecraft, patch and sound is generated by code, so the site works
without downloading any asset.

## Run locally

    npm ci
    npm run dev        # http://localhost:5173
    npm run test       # unit and data tests
    npm run test:e2e   # Playwright + axe

Requires Node.js 20.19+ or 22.12+. Optional public-domain textures: `npm run assets` (see Annex C in `CREDITS.md`).

## Deploy

`npm run build` produces a static `dist/`. GitHub Pages deploys automatically from `main` through
`.github/workflows/pages.yml` (enable Pages with "Source: GitHub Actions"). The workflow runs
`scripts/spa-routes.mjs`, which copies `index.html` to every known route so deep links answer with HTTP 200. Vercel uses `vercel.json` and Netlify uses
`public/_redirects` to rewrite deep links to `index.html`.

`public/og-image.png` and the no-JavaScript reading pages (`public/lectura-es.html`, `public/lectura-en.html`) are generated
from the built app and committed. After changing the story texts, regenerate them with `npm run build`, then
`npx vite preview --port 4173` and `npm run prerender` in another terminal.

## Accessibility

Keyboard-only navigation, screen-reader scene descriptions, text for everything you can hear, high-contrast
and legible-font modes, reduced motion, lite mode, a reading mode without WebGL and static reading pages that need no JavaScript.
